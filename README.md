## 💡 What I Bring

- **🧮 Complex business logic:** Statutory payroll for **GSIS, PhilHealth, Pag-IBIG, SSS, and BIR withholding tax**, loans, earnings, and leave credits, including fixing bracket-ceiling, employer-share, and duplicate-deduction defects in live payroll data
- **🔐 Security-minded:** Found and fixed 4 classes of data-access flaw in a self-service portal, including an insecure direct object reference (IDOR) in leave filing and missing record-ownership checks
- **🗄️ Database design:** Schemas across **404 migrations and 263 models**, with cross-system integration between HRIS, payroll, and budget databases on **MySQL and PostgreSQL**
- **🏗️ End-to-end ownership:** Requirements → database → Laravel backend → Vue.js UI → PDF & Excel reports → staging and production releases
- **🛡️ Safe production fixes:** Built data-integrity tools that detect and repair drift in live records, with dry-run-by-default repairs routed through approval workflows instead of direct SQL edits

## 🏆 Featured Projects

> 🔒 These are **client systems in private company repositories**, so I show them by scope and impact instead of source code.

### 🧾 Government Payroll System
**Green Apple Technology** · Laravel · Vue.js · MySQL
> Turns biometric time logs into daily time records and computes each cut-off's pay for **~2,500 employees**.
- Built the `.DAT` biometric upload flow that cut DTR processing from **weeks to within a day**
- Implemented GSIS, PhilHealth, Pag-IBIG, SSS, and withholding tax computation
- Produces payslips, the General Payroll register, and per-agency remittance reports (PDF & Excel)
- Deployed for a city and a municipal government

### 🏢 Human Resource Information System (HRIS)
**Green Apple Technology** · Laravel · Vue.js · MySQL
> HR platform with **14 role-gated modules** covering the full employee lifecycle.
- Employee 201 files, recruitment, leave credits, service records, salary grades, and performance ratings
- Shares employee and department data with the payroll and budget systems
- Deployed for a city and a municipal government

### 👤 Employee Self-Service Portal (ESSP)
**Green Apple Technology** · Laravel · Vue.js · MySQL
> Lets government employees handle HR tasks from their own phone instead of lining up at the HR office.
- View payslips and loans, file leave, dispute time records, and prepare asset declarations (SALN)
- Supervisor approvals built into the same portal
- Led the mobile optimization (tables, modals, and print output) and the security hardening

### 🛺 Business Permit, Real Property Tax & Franchising Systems
**Green Apple Technology** · Laravel · Vue.js · PostgreSQL
> Permits, real property tax, tricycle franchises (MTOP), and fishing boat registration.
- Franchising system manages **13,000+ MTOP applications** and **3,800+ registered tricycles** for a city government
- Delivered a land and building reclassification module inside a legacy vendor's **live PostgreSQL** tax system without disrupting existing data
- Maintained and extended the franchising system across two city deployments since Apr 2025

### 📝 Resume Maker *(personal project)*
Laravel · Livewire · Tailwind CSS · MySQL · Claude API
